# Telco Customer Churn Prediction

This repository contains a full Data Science portfolio project analyzing Telco customer data to predict churn using machine learning.

## Project Structure

- `index.html`: The main portfolio website, ready to be deployed via GitHub Pages. Contains the interactive analysis, visualizations, and code walkthroughs.
- `images/`: Static visual assets extracted from the data analysis used in the HTML presentation.
- `src/`: The raw source code.
  - `Churn_prediction.ipynb`: A Jupyter Notebook containing the full end-to-end pipeline (EDA, preprocessing, feature engineering, and modeling).

## Viewing the Analysis

You can view the full interactive analysis live at [https://vikash-kys.github.io/telco-churn-prediction/](https://vikash-kys.github.io/telco-churn-prediction/).

## Running Locally

To run the machine learning pipeline yourself:

1. Clone this repository.
2. Install the necessary Python packages (`pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`).
3. Navigate to the `src/` folder and open the `Churn_prediction.ipynb` notebook in Jupyter.
